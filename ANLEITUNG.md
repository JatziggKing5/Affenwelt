# Game Day bei Olai: So baust du dein Spiel

Die ganze Anleitung mit Kopier-Knöpfen: Datei `GameDay/installer/index.html` im Browser öffnen.

## Claude starten
Im Terminal:
    cd ~/GameDay/mein-spiel
    claude

## Die 5 Regeln
1. Genau sagen, was du willst.
2. Eine Sache aufs Mal.
3. Wenn etwas nicht geht: «Es geht nicht. Im Browser passiert X. Ich wollte Y.»
4. Roter Fehler im Browser: F12 (Mac: Cmd + Option + I), Reiter «Console», roten Text an Claude geben.
5. Claude fragt, bevor es etwas tut. Lesen, dann bestätigen.

## Dein erster Auftrag
Baue ein 3D-Spiel: Ein Würfel steht auf einem grünen Boden. Mit den Pfeiltasten bewegt er sich, mit der Leertaste springt er.
